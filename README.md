# 🌤 WeatherAppWPF — Desktop Weather Application

**WeatherAppWPF** is a Windows desktop application for viewing weather information, built with **C#** and **WPF**.  
It provides a clean and modern interface to quickly check current weather and forecasts, similar to the default Windows weather app.

---

## 🚀 Features
- 🌡 View **current weather** for any city.  
- 📅 Display **forecast** for the next days.  
- 🌐 Fetches data from a public weather API (e.g., OpenWeatherMap).  
- 🖥 Built with **WPF**, showcasing modern desktop UI techniques.  
- 🧩 Modular architecture with separation of UI and business logic.

---

## 🧱 Architecture
- **Views** — WPF XAML files for UI (MainWindow.xaml).  
- **ViewModels** — implements MVVM pattern for data binding and UI updates.  
- **Models** — data structures representing weather information.  
- **Services** — handles API requests and data parsing.
